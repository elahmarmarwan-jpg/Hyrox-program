# HYROX 18-Week Program

A free, mobile-friendly 18-week HYROX training plan: strength, running, station work and race simulations.

- Pick the date your week 1 starts and the calendar adapts.
- Tap any session to log sets, splits, times, RPE and notes.
- Swap strength exercises for alternatives.
- No sign-up: scores are saved in your own browser. Use **Export backup** / **Import backup** to move them between devices.
- Opened inside Claude (signed in), the same page saves to your account and syncs across all your devices automatically.

Live site: https://<username>.github.io/hyrox-program/

The whole site is a single `index.html` with no build step, served by GitHub Pages.

Not affiliated with HYROX. Train within your limits.
